## 概要
Plangothic Project（プランゴシック・プロジェクト、中国語：遍黑體項目、遍黑体项目）は、[源ノ角ゴシック](https://github.com/adobe-fonts/source-han-sans)をベースに、中国大陸の字形を標準として、CJK 統合漢字の拡張ブロックの字形を補完するプロジェクトです。「プランニヴァース」（Planiverse）のサブプロジェクトで、2020 年 6 月頃に始まりました。

## 収録範囲
本フォントは、主に CJK 統合漢字拡張 B から拡張 J までのすべての漢字を収録しています。そのほかのブロックにも一部の文字を収録しています。

## よくある質問
### 1. なぜ Plangothic のフォントファイルは 2 つあるのですか？
- 1 つのフォントに収録できるグリフ数の上限は 65,535 ですが、CJK 統合漢字の総数はこの上限を大きく上回るためです。
### 2. なぜこのプロジェクトには URO（基本ブロック）と拡張 A の漢字が少量含まれているのですか？
- 本プロジェクトの目的は [源ノ角ゴシック](https://github.com/adobe-fonts/source-han-sans)の補完です。基本ブロックと拡張 A の漢字を表示するには、源ノ角ゴシックをそのまま使用できます。本プロジェクトに収録している基本ブロックと拡張 A の漢字は、Unicode で字形が変更されたもの、または本プロジェクトの趣旨に合わないものです。これらの漢字は、追加前に他の主要フォントや Unicode のコードチャートに掲載されている字形と比較しています。
### 3. 将来、他のウェイト（または他地域のグリフ）を追加する予定はありますか？
- プロジェクトの作業量が膨大なため、その予定はありません。必要に応じて、本プロジェクトをもとにご自身の用途に合った派生フォントを作成できます。
### 4. なぜこのフォントは複雑な文字体系の組版（Complex Text Layout、CTL）や漢字異体字シーケンス（Ideographic Variation Sequence、IVS）に対応していないのですか？
- 本プロジェクトのフォントは、[Unifont](https://unifoundry.com/unifont)のように、組版を目的とせず、字形を表示するためのツールとして作られています。CTL で複雑な文字体系を正確に組版する機能や、漢字異体字シーケンス（IVS）で他地域の字形を表示する機能は、本プロジェクトの対象外です。必要に応じて、ご自身の用途に合った派生フォントを作成できます。
### 5. 本プロジェクトの TTC（複数の TrueType フォントをまとめたもの）は、スマートフォンやソフトウェアでそのまま使えますか？ スマートフォンに直接インストールして、収録されているすべての字形を表示できますか？ この問題はすべてのプラットフォームで起きますか、それとも特定のプラットフォームだけですか？
- 本プロジェクトの TTC は Windows で通常どおり使用できます。スマートフォンに TTC ファイルを直接インストールすると、収録フォントのうち 1 つ（通常は P1）に含まれる字形しか表示できず、すべての字形を同時に表示することはできません。ソフトウェアですべての字形を表示するには、特別な設定が必要な場合があります。TTC の互換性はプラットフォームによって異なり、多くの場合は追加の手順が必要です。
### 6. 各配布版の違いは何ですか？
- **Super版**：すべての形式のフォントファイルを含むため、パッケージサイズが比較的大きいです。
- **Static版**：P1とP2の2つの独立したTTFフォントファイルと1つのTTCファイルを含みます。
- **OTF版**：OpenType形式のフォントファイルとTTC/OTCファイルを含みます。
- **Web版**：WOFF2形式のウェブフォントファイルです。
- **個別のTTFファイル**：Static版から直接抽出したもので、個別にダウンロードして使いやすくなっています。

**圧縮形式**　.7z と .zip の内容は同じで、圧縮率だけが異なります。.7z はファイルサイズが小さくなりますが、別途解凍ソフトが必要な場合があります。.zip はファイルサイズがやや大きいものの、OS の標準機能で解凍できます。

**基本インストール方法：**

1. **フォントのインストール**：個別の TTF ファイル 2 つ、または TTC ファイル 1 つをダウンロードし、右クリックして「すべてのユーザー用にインストール」を選択します（管理者権限が必要です）。
2. **フォールバックの設定**：`registry/Plangothic-Install.reg` をダブルクリックして実行します（管理者権限が必要です）。
3. **再ログイン**：設定を有効にするには、Windows アカウントからサインアウトし、再度サインインします。
4. **アンインストール**：フォントは対象のファイルを削除してアンインストールします。フォールバックのレジストリ設定は `registry/Plangothic-Uninstall.reg` を実行して削除します。

> 高度な使い方や詳細については、[実験的なフォールバック設定の説明](./registry/Experimental/README.md)をご覧ください。

## 「プランニヴァース」（Planiverse）について
このフォントファミリーは Fitzgerald が 2023 年 12 月に立ち上げました。現在、以下のプロジェクトが含まれています。
1. **Plangothic Project（プランゴシック・プロジェクト、中国語：遍黑體項目、遍黑体项目）**：源ノ角ゴシックをベースに、中国大陸の字形を標準として、CJK 統合漢字の拡張ブロックの字形を補完するプロジェクトです。
    - **プロジェクトステータス**：Unicode の最新版への対応を継続しています。
2. **Planwritzen Project（プランライト・プロジェクト、中国語：遍蕤體項目、遍蕤体项目）**：Fitzgerald 自身の手書き文字をベースに、Plangothic Project の字形を標準とするフォントプロジェクトです。収録範囲は暫定的に源ノ角ゴシックと Plangothic を合わせた範囲で、今後拡張する可能性があります。
    - **プロジェクトステータス**：プロジェクト本体は作成されていますが、プロジェクトホームページは作成されていません。
3. **Planschrift Project（プランシェフト・プロジェクト、中国語：遍玨體項目、遍玨体项目）**：Huiwen-Mincho（匯文明朝体）をベースに、CJK 統合漢字の拡張ブロックの字形を補完するプロジェクトです。収録範囲は暫定的に、匯文明朝体の収録範囲を源ノ角ゴシックと Plangothic を合わせた範囲まで拡張する予定です。
    - **プロジェクトステータス**：プロジェクト本体と[プロジェクトホームページ](https://github.com/Fitzgerald-Porthmouth-Koenigsegg/Planschrift_Project)を作成しましたが、完了していません。
4. ***Planseal Project（プランシール・プロジェクト、中国語：遍篆體項目、遍篆体项目）***：『説文解字』の小篆をベースに、CJK 統合漢字の拡張ブロックの字形を補完するプロジェクトです。
    - **プロジェクトステータス**：Unicode 18.0 で小篆ブロックが追加されたため、Plangothic Project、Planwritzen Project、Planschrift Project に統合され、それぞれの一部となりました。
5. **Planicon Project（プランイコン・プロジェクト、中国語：遍象體項目、遍象体项目）**：字統網（Zitools）の一部の漢字アイコンをもとに字形を補完するプロジェクトです。収録範囲は暫定的に基本ブロックと拡張 A で、ほかの漢字ブロックにも一部の字形を収録しています。
    - **プロジェクトステータス**：プロジェクト本体は作成されていますが、ホームページは未作成です。プロジェクト名は暫定です。
6. **Plantsing Project（プランツィン・プロジェクト、中国語：遍擎體項目、遍擎体项目）**：武英殿版『康熙字典』をベースに、CJK 統合漢字の拡張ブロックの字形を補完するプロジェクトです。収録範囲は暫定的に Plangothic Project と同じです。
    - **プロジェクトステータス**：プロジェクト本体とホームページはいずれも未作成です。
7. ***Plangul Project（プラングル・プロジェクト、中国語：遍訓體項目、遍训体项目）***：源ノ角ゴシックをベースに、ハングルを漢字の形で表す字形を制作するプロジェクトです。収録範囲は暫定的に基本ハングルと拡張ハングルです。
    - **プロジェクトステータス**：Plangothic Project に統合され、その一部となりました。
8. **Planfixibit Project（プランフィジビト・プロジェクト、中国語：遍繕體項目、遍缮体项目）**：[Fixedsys Excelsior](https://github.com/kika/fixedsys)をベースに、Unicode の最新版に合わせて文字を追加するプロジェクトです。
    - **プロジェクトステータス**：プロジェクト本体とホームページはいずれも未作成です。プロジェクト名は暫定です。
9. **Plantone Project（プラントウン・プロジェクト、中国語：遍磊体项目、遍磊體項目）**：『開成石経』をベースに、CJK 統合漢字の拡張ブロックの字形を補完するプロジェクトです。
    - **プロジェクトステータス**：プロジェクト本体とホームページはいずれも未作成です。プロジェクト名は暫定です。
